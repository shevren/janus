# Plan

Use for multi-step coding, debug, or install-and-wire jobs.

1. Call the plan tool with a goal and numbered steps. Not a novel.
2. Wait. Do not execute until Allow once.
3. Skip for one lookup, conversion, or a job already approved this turn.
4. After Allow once, the user switches to Build to run it.
